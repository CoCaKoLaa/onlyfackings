# ONLYFACKINGS static website

This folder contains the website files:

- index.html: home page and 18+ entry screen
- styles.css: responsive colors, layout, and visual design
- app.js: age confirmation, creator filters, mobile menu, and demo dialogs
- robots.txt and sitemap.xml: crawler discovery
- wrangler.jsonc: Cloudflare Workers static asset setup

## Publish from GitHub

1. Upload all these files into the root of the CoCaKoLaa/onlyfackings repository.
2. Replace the existing index.html. Add styles.css, app.js, robots.txt, sitemap.xml, and wrangler.jsonc.
3. Keep the filenames and lowercase spelling exactly as shown.
4. Commit to the main branch and wait for the Cloudflare deployment to say Ready.
5. Visit https://onlyfackings.com and refresh with Ctrl+F5.

This is a static visual prototype. The example creator profiles are fictional. Registration, subscriptions, and payments are not connected to a backend. The age screen is self-attestation, not identity or age verification.
